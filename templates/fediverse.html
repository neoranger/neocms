Cómo conectar

Token manual (recomendado)

  1. Entrá a tu instancia y abrí Preferencias → Desarrollo.
  2. Creá una aplicación nueva con el permiso write:statuses (solo publicar).
  3. Copiá el token de acceso y pegalo en el formulario.
  4. Guardá: NeoCMS verifica la cuenta y consulta el límite de caracteres.

Usuario y contraseña

Disponible en instancias que aceptan password grant. NeoCMS registra una app automáticamente si hace falta. La contraseña se usa solo para obtener el token y no se guarda, no se muestra y no se registra. Si tenés 2FA, agregá el código actual.

Podés revocar el token desde la instancia cuando quieras. Diaspora y Bluesky no usan esta integración.
